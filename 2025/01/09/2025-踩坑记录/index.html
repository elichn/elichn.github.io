时间反序列化问题 - 2025-06-19

海外支付，接入onerway支付，支付回调时，时间反序列化有问题，回调给的是北京时间，字符串

直接反序列化时时间比北京时间快了8个小时。

https://docs.onerway.com/apis/zh/v0.6/transaction-notification

代码中接受直接将字符串转成Date，没有加时区，造成时间有问题。

解决：加上时区，这样就是北京时间

还有另一个解决方式，接受使用String 接收，然后手动转成Date，这样肯定不会有问题。线上解决使用第一种方式，这样方式最快。

k8s权限问题 - 2025-02-24

java 服务 在k8s 新建的namespace 起不来，一直卡住.

但在原来的namespace 能起来。k8s新建了一个集群，原因是服务调用k8s注册发现调不通。

如何定位到的：

容器中执行健康检查报如下错误：

curl http://localhost:9858/actuator/health

应该是新版k8s把这个权限回收了。devops手动修改解决

maven 问题- 2025-01-09

宙斯发布client，maven发布jar不成功，报错如下

https://zeus.corp.*.club/portal/app/reviewPublishTask?appCode=business-hs-cos-client&jenkinsBuildId=10&env=prod&appType=JAR

刚开始以为是宙斯maven有问题，最后看详细错误才发现，代码合错分支了，合到之前的迭代分支，之前版本号已经发过maven-releases了，再次发相同的版本号就会报这个错误 Return code is: 400, ReasonPhrase: Repository does not allow updating assets: maven-releases.

重新合到正确的迭代分支，发布成功。还有一个问题服务发布要选择正确的k8s namespace。
